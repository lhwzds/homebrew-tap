# Homebrew Tap

## Installation

```bash
brew tap lhwzds/tap
brew install restloop
brew install codocia
```

## Formulae

- [restloop](https://github.com/lhwzds/restloop): minimal coding-agent loop (macOS, Linux x86_64)
- [codocia](https://github.com/lhwzds/codocia): documentation drift checker for AI coding agents
